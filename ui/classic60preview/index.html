WoWSims Forever Experimental preview

Classic 60 baseline lab

A small, inspectable foundation for a future level-60 simulator. Choose a character and check the starting numbers.

This is not a DPS simulator.

These are unequipped, untalented, humanoid character stats, with optional passive racial effects. There are no gear, spell, talent, pet or combat simulations here. The main simulator remains on its inherited TBC level-70 rules.

This preview reproduces a pinned Classic source-code reference, not verified in-game Forever mechanics.

What these numbers mean

Unsupported or unknown Forever changes are intentionally excluded. A matching reference calculation is a regression check, not a claim that a game mechanic has been confirmed.

Known source omissions are preserved for now: Hunter, Mage and Priest have no Agility-to-Dodge dependency, and Mage and Priest have no Agility-to-physical-crit dependency. These are not claims about correct in-game Classic behavior.
